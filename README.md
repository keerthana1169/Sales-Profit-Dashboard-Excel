# Sales-Profit-Dashboard-Excel
Interactive Sales &amp; Profit Dashboard using Excel

## Project Overview
Built an interactive dashboard using Excel to analyze:
- Sales performance
- Profit trends
- Customer insights
- Regional analysis

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- KPI Cards

## Features
- Sales by Category
- Profit by Year
- Monthly Trends
- Top Customers
- Interactive Filters
